# barcode-pro datasets

The benchmark images of [barcode-pro](https://github.com/kamilkrzywanski/barcode-pro), which mounts
this repository as the submodule `datasets`. They are not under barcode-pro's Apache License; each
set keeps its own:

- `artelab-medium-barcode-1d/`: Arte-Lab Medium Barcode 1D, 430 phone photos of EAN-13 labels with
  their digits, by Zamberletti et al. ([VISAPP 2010](https://doi.org/10.5220/0002811600050011)),
  [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). `Readme.txt` is the authors' own.
- `zxing-cpp-3.1.1/`: test samples of [zxing-cpp](https://github.com/zxing-cpp/zxing-cpp) 3.1.1
  that barcode-pro does not already keep in `src/test/resources`, Apache License 2.0. See
  `SOURCE.txt`.
